## Что сделано в 0.2.0

Тикеты `.scratch/sql-coding-standard-v2/issues/01–05` реализованы:

- **`FMT-004`** — термин «корневое ключевое слово» взят из глоссария; короткий
  многострочный запрос — норма, однострочный запрещён (уровень и `LT14` без
  изменений).
- **`FMT-008`** — `distinct` остаётся на строке с `select`.
- **`FMT-009`** — пример CTE приведён к канону (само правило — про отступ).
- **`FMT-011`** — **удалено** (пустая строка между CTE противоречит канону).
- **`FMT-012`** — поднято `SHOULD` → `MUST`; запрет блочных комментариев `/* */`
  в репозитории (ADR-0006).
- **`FMT-014`** (новое, `SHOULD`) — расположение однострочных комментариев.
- **`FMT-015`** (новое, `SHOULD`) — канон вложенных блоков: `on` и CTE.
- Конфиг: секция `[sqlfluff:layout:type:common_table_expression]
  spacing_within = single` добавлена в **оба** профиля; `LT08`
  (`layout.cte_newline`) намеренно **не** включён.
- `GLOSSARY.md` — термин «Корневое ключевое слово»; `docs/adr/0006-no-block-comments.md`.

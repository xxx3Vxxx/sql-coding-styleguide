# 04: Процесс: версии, изменение, отступления, внедрение

**What to build:** §7 и §8 стандарта — как документ живёт во времени и как им пользуются команды. Сюда входит версионирование, статусы, порядок предложения изменений, механизм отступлений и поэтапное внедрение линтера.

**Blocked by:** 01 (Сквозной каркас и конвейер проверки)

**Status:** ready-for-agent

- [ ] Описано версионирование `MAJOR.MINOR.PATCH` с определениями каждого уровня; `1.0` = первое утверждение центром компетенций
- [ ] Описаны статусы `Draft` / `Active` / `Deprecated`
- [ ] Описан порядок внесения изменений (через PR в репозитории как источник истины)
- [ ] Описан механизм отступлений команд по ADR-0004: понижение уровня и точечное отключение разрешены, переопределение в противоположное — нет, отступления живут в локальном документе команды
- [ ] Описан владелец/approver: до публикации — куратор, после — центр компетенций
- [ ] Описано поэтапное внедрение линтера с переходным периодом

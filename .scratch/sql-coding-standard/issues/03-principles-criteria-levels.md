# 03: Принципы, критерии, уровни нормативности

**What to build:** §2–§4 стандарта — мировоззренческий и оценочный каркас, на который опираются все правила. Принципы объясняют «почему», критерии дают инструмент сравнения вариантов, уровни задают силу предписаний.

**Blocked by:** 01 (Сквозной каркас и конвейер проверки)

**Status:** ready-for-agent

- [ ] Шесть принципов с формулировками: Минималистичность, Эксплицитность, Естественность (least surprise), Однозначность, Единообразие, Оправданность
- [ ] Явно введён мета-принцип «единообразие важнее выбора»
- [ ] Семь измеримых критериев с пояснением, что часть из них — рамка без строгой эмпирики
- [ ] Таблица уровней `MUST`/`SHOULD`/`MAY` с русскими значениями и связью с RFC 2119 (описано один раз)

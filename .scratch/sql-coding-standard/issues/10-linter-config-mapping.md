# 10: Конфиг линтера: два профиля, маппинг, проверка согласованности

**What to build:** готовый к применению референсный конфиг линтера в двух профилях — базовом (`errors` only) и полном (aspirational) — плюс таблица соответствия «ID правила стандарта ↔ правило линтера» и скрипт, который ловит расхождения между документом и конфигом.

**Blocked by:** 05, 06, 07, 08, 09 (все правила аспектов)

**Status:** ready-for-agent

- [ ] Конфиг разделён на два профиля: базовый (`MUST`/`error`) и полный (`SHOULD`/`warning`)
- [ ] Уровни согласованы с §4: `MUST` ↔ `error`, `SHOULD` ↔ `warning`
- [ ] Таблица маппинга покрывает все непустые правила `FMT`/`NAM`/`SYN`, у каждого — признак «проверяется линтером»
- [ ] Скрипт сверяет ID правил в документе и в конфиге: нет правила без ID и нет ID без правила
- [ ] Прогон обоих профилей по корпусу примеров — зелёный

# 09: Синтаксис: ядро (`SYN-001`–`SYN-007`)

**What to build:** ядро аспекта «Синтаксис» для v1.

Правила: `SYN-001` явный тип `JOIN`, `SYN-002` CTE вместо подзапросов, `SYN-003` `<>` вместо `!=` (уже заведено каркасом — довести до формата), `SYN-004` `IS NULL`/`IS NOT NULL`, `SYN-005` явный `AS` для алиасов, `SYN-006` ограничение `SELECT *`, `SYN-007` квалификация колонок при нескольких источниках.

**Blocked by:** 01 (Сквозной каркас и конвейер проверки)

**Status:** ready-for-agent

- [ ] Для каждого из семи правил выбран один вариант с обоснованием по критериям
- [ ] У каждого правила: ID, уровень, пример «плохо/хорошо», обоснование, поле «проверяется линтером»
- [ ] Конфиг линтера дополнен соответствующими правилами
- [ ] В корпусе примеров есть пара «плохо/хорошо» на каждое правило
- [ ] Скрипт проверки — зелёный

## Decisions

- `SYN-006` — полный запрет `SELECT *` (без исключения для финального CTE).
- Открытый хвост: «финальная `;`» не входит в инвентарь v1 — решить отдельно (в бэклог или в v1) после основной сборки.

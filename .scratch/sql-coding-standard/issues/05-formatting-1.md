# 05: Форматирование, часть 1 (`FMT-001`–`FMT-007`)

**What to build:** первая половина аспекта «Форматирование» — правила, определяющие базовую геометрию SQL-текста. Для каждого правила: формулировка, уровень, пример «плохо/хорошо», обоснование, запись в конфиг линтера.

Правила: `FMT-001` символ отступа, `FMT-002` ширина отступа, `FMT-003` максимальная длина строки, `FMT-004` переносы root keyword, `FMT-005` запятые (leading/trailing), `FMT-006` регистр ключевых слов и функций, `FMT-007` пробелы вокруг операторов и после запятых.

**Blocked by:** 01 (Сквозной каркас и конвейер проверки)

**Status:** done

## Decisions

Спорные варианты внутри правил зафиксированы владельцем (2026-10-31):

- `FMT-002` — отступ **4 пробела** (пробел, не таб; принцип «естественность»).
- `FMT-003` — максимальная длина строки **120** символов.
- `FMT-005` — запятые **trailing** (в конце строки; совпадает с дефолтом SQLFluff).
- `FMT-006` — регистр ключевых слов и функций **lower** (меньше переключений регистра и ручной работы).

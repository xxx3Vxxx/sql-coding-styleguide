# 08: Нейминг, часть 2 (`NAM-008`–`NAM-014`)

**What to build:** вторая половина аспекта «Нейминг» — именование объектов БД и конструкций запроса.

Правила: `NAM-008` первичный ключ, `NAM-009` внешние ключи, `NAM-010` индексы и констрейнты, `NAM-011` схемы/представления/последовательности, `NAM-012` алиасы и корреляции, `NAM-013` имена CTE, `NAM-014` функции и их параметры.

**Blocked by:** 01 (Сквозной каркас и конвейер проверки), 07 (Нейминг, часть 1)

**Status:** ready-for-agent

- [ ] Для каждого из семи правил выбран один вариант с обоснованием по критериям
- [ ] У каждого правила: ID, уровень, пример «плохо/хорошо», обоснование, поле «проверяется линтером»
- [ ] Выбранные варианты согласованы с частью 1 (единый стиль регистра и словообразования)
- [ ] Конфиг линтера дополнен там, где правило проверяемо
- [ ] Скрипт проверки — зелёный

## Decisions

- `NAM-008` — первичный ключ называется **`id`** (`users.id`); `<table>_id` оставить для внешних ключей.
- `NAM-012` — короткие алиасы **допустимы**, но **без инициализмов** (аббревиатур): `o` — ок, `oi` — нет.

Без прецедентного консенсуса (имплементатор предлагает один вариант с обоснованием по критериям, владелец подтверждает): `NAM-009` (FK), `NAM-010` (индексы/констрейнты), `NAM-011` (схемы/представления/последовательности), `NAM-013` (CTE), `NAM-014` (функции и параметры).

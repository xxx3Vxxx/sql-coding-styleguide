**What to build:** новое `SHOULD`-правило `FMT-014`: однострочный комментарий — на отдельной строке **над** описываемым кодом. Исключение — служебные директивы тулинга. Правило линтером не проверяется (`нет`).

## Decisions

- Комментарий внутри списка — тоже своей строкой (пример из предложения).

# Стандарт кодирования SQL

Проект по разработке общекорпоративного регламентирующего документа для кода на SQL (основная СУБД — PostgreSQL, второстепенно SQLite; нагрузка OLTP). Источник истины — этот репозиторий; публикация — Confluence.

## Language

**Стандарт кодирования SQL**:
Регламентирующий документ, задающий правила оформления кода на SQL.
_Avoid_: стайлгайд, стайл гайд, код-стайл, гайдлайн

**Принцип**:
Общий подход, определяющий, почему правила формулируются именно так (например, эксплицитность, минималистичность).
_Avoid_: постулат, догма

**Аспект**:
Область кодирования, для которой стандарт задаёт правила (например, форматирование, нейминг, синтаксис).
_Avoid_: раздел, тема, категория (когда имеется в виду именно аспект)

**Корневое ключевое слово** (root keyword):
Ключевое слово, открывающее корневое предложение запроса: `select`, `from`, `where`, `join`, `group by`, `order by`, `having`, `limit`, `offset` и т. п. Не являются корневыми `on`, `and`/`or`, `distinct`, а также операторы множеств (`union`).
_Avoid_: главное ключевое слово, корневой keyword

**Правило**:
Конкретное предписание стандарта внутри аспекта, имеющее идентификатор, уровень нормативности, пример и обоснование.
_Avoid_: пункт, требование

**Критерий**:
Измеримая величина, по которой сравниваются варианты оформления кода (например, шум в diff, когнитивная нагрузка).
_Avoid_: метрика (когда имеется в виду оценочный критерий отбора правил)

**Уровень нормативности**:
Степень обязательности правила: `MUST` (обязательно), `SHOULD` (следует), `MAY` (допускается). Теги английские, значения фиксируются один раз в документе.
_Avoid_: приоритет, важность

**Отступление**:
Легитимное отклонение команды от правила корпоративного стандарта, документируемое на стороне команды и не меняющее общекорпоративный документ.
_Avoid_: исключение, нарушение, waiver

**Центр компетенций**:
Орган, который разрабатывает и утверждает корпоративный стандарт.
_Avoid_: комитет (разговорный синоним)

**Референсный конфиг линтера**:
Готовый к применению файл конфигурации линтера (SQLFluff), реализующий правила стандарта.
_Avoid_: настройки линтера, пресет

# plpgsql вне области стандарта

Стандарт описывает только текст на SQL: запросы, функции `LANGUAGE sql`, DDL-миграции. Тела функций и процедур на plpgsql не рассматриваются.

Граница совпадает с техническим ограничением выбранного линтера: SQLFluff не линтует тела plpgsql. Благодаря этому весь стандарт остаётся машинно-проверяемым.

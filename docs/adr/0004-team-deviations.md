# Отступления команд от стандарта

Команда может **понижать** уровень правила (`MUST`→`SHOULD`/`MAY`) или точечно **отключать** правило для себя, но не может переопределять правило в противоположное и не может повышать чужие `SHOULD` в `MUST`.

Отступления фиксируются в локальном документе команды со ссылками на ID правил и не меняют общекорпоративный документ. Корпоративный стандарт описывает сам механизм, но не перечисляет отступления команд.

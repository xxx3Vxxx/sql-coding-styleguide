# Покрытие аспектов кодирования

Стандарт покрывает **Форматирование** и **Нейминг** полностью, **Синтаксис** — частично (ядро в v1), а **Дизайн БД**, **Производительность** и **Безопасность** вынесены за рамки как специфичные для конкретных проектов и компетенций.

Обоснование: обзор публичных SQL-гайдов (`docs/research/sql-style-guides.md`) показал, что ядро у всех — формат + имена + синтаксис; дизайн осмысленно покрывает лишь один гайд, производительность — один, безопасность — фрагментарно.
